Pencil

简介 Pencil(点格棋)，又名点点连格棋，是一种双人添子类游戏

游戏规则

棋盘：由N*N的点(边)组成，(坐标从0开始，先x后y, 原点在左上角，本游戏N=11)

Y

1.每局比赛由红方先手；

2.双方轮流选择横向或竖线相邻的两个点，将它们连成一边——占边，不可越点，不可重边；

3.当一个格子的四条边均被占满，则最后一个占边者获取这个格子;

4.当一方在占边时捕获了格子，则该方继续占边。该轮添子结束的标志是占边后未获取格子；

5.占领格子较多的一方为获胜方。

具体交互内容

JSON 交互

每回合Bot的request是一个JSON对象，表示对方占边位置。格式如下： 

{
                   "x": Number, // 边的横坐标
                   "y": Number, // 边的纵坐标
                   "pass": Number, // 是否需要pass，如为1则直接输出 -1 -1
 }

Bot所需要输出的response也是JSON对象，表示占边的横纵坐标。 

{
                   "x": Number, // 边的横坐标
                   "y": Number, // 边的纵坐标
 }

如果是红方的第一手，则 request 为 {"x": -1, "y": -1, "pass" : 0}

游戏样例程序

JSON 交互的 Python 样例程序

C++程序的本地编译方式请参看JSONCPP。 

import json
import random


class GameState:
    def __init__(self, xsize, ysize):
        self.board = []
        self.grid_edge = 4
        self.grid_edge_used = 5
        self.grid_box = 2
        self.grid_dot = 3
        self.player_red = 0
        self.player_blue = 1
        self.curr_player = self.player_red
        self.dirs = [[-1, 0], [1, 0], [0, -1], [0, 1]]
        self.xsize = xsize
        self.ysize = ysize
        self.scores = [0, 0]
        for x in range(xsize):
            tmp_list = []
            for y in range(ysize):
                if x % 2 == 0:
                    if y % 2 == 0:
                        tmp_list.append(self.grid_dot)
                    else:
                        tmp_list.append(self.grid_edge)
                else:
                    if y % 2 == 0:
                        tmp_list.append(self.grid_edge)
                    else:
                        tmp_list.append(self.grid_box)
            self.board.append(tmp_list)
    def display_board(self):
        for y in range(self.ysize):
            plist = []
            for x in range(self.xsize):
                plist.append(self.board[x][y])
            print(plist)
    def is_position_edge(self, x, y):
        return (x + y) % 2 != 0
    def is_position_box(self, x, y):
        return x % 2 != 0 and y % 2 != 0

    def inBoard(self, x, y):
        return 0 <= x < self.xsize and 0 <= y < self.ysize

    def update_state(self, x, y):
        scored = False
        for id in range(4):
            xx = x + self.dirs[id][0]
            yy = y + self.dirs[id][1]
            if self.inBoard(xx, yy) and self.board[xx][yy] == self.grid_box:
                num_lines = 0
                for pi in range(4):
                    xxx = xx + self.dirs[pi][0]
                    yyy = yy + self.dirs[pi][1]
                    assert self.inBoard(xxx, yyy)
                    if self.board[xxx][yyy] == self.grid_edge_used:
                        num_lines = num_lines + 1
                if num_lines == 4:
                    scored = True
                    self.scores[self.curr_player] = self.scores[self.curr_player] + 1
        return scored

    def do_action(self, x, y):
        assert self.board[x][y] == self.grid_edge
        self.board[x][y] = self.grid_edge_used
        scored = self.update_state(x, y)
        return scored

    def legal_actions(self):
        actions = []
        for x in range(self.xsize):
            for y in range(self.ysize):
                if self.board[x][y] == self.grid_edge:
                    actions.append((x, y))
        return actions

    def give_random_response(self):
        actions = self.legal_actions()
        chose_id = random.randint(0, len(actions)-1)
        return actions[chose_id]

    def act_as_ai(self):
        full_input = json.loads(input())
        all_requests = full_input["requests"]
        all_responses = full_input["responses"]
        for i in range(len(all_requests)-1):
            cx = all_requests[i]['x']
            cy = all_requests[i]['y']
            self.curr_player = 1 - self.curr_player
            if cx != -1:
                self.do_action(cx, cy)
            rx = all_responses[i]['x']
            ry = all_responses[i]['y']
            self.curr_player = 1 - self.curr_player
            if rx != -1:
                self.do_action(rx, ry)
        lat_req = all_requests[-1]
        cx = lat_req['x']
        cy = lat_req['y']
        self.curr_player = 1 - self.curr_player
        if cx != -1:
            opp_should_continue = self.do_action(cx, cy)
        else:
            opp_should_continue = False
        self.curr_player = 1 - self.curr_player
        if lat_req['pass'] == 1:
            assert opp_should_continue
            resp = (-1, -1)
        else:
            resp = self.give_random_response()
        print(json.dumps({'response': {'x': resp[0], 'y': resp[1]}}))


if __name__ == '__main__':
    msize = 5
    game_state = GameState(msize * 2 + 1, msize * 2 + 1)
    game_state.act_as_ai()
